# This is the canonical, exact-pinned set for a clean, repository-local
# training/test venv. It is intentionally SEPARATE from the shared ComfyUI
# environment: install it in its own venv (see scripts/setup_env.sh) so it
# never mutates the ComfyUI env or any global site-packages.
#
#   python3 -m venv .venv
#   .venv/bin/python -m pip install --upgrade pip
#   .venv/bin/python -m pip install -r requirements-training.txt
#   .venv/bin/python -m pip check        # must print "No broken requirements found."
#
# The base package is standard-library only (pyproject `dependencies = []`), so
# the server, client, and rules backend need none of the below. Everything here
# is for the opt-in local DistilBERT training path and the test suite (which
# exercises the calibration end-to-end test).
#
# WHY THE huggingface-hub UPPER BOUND IS <1.0
# ------------------------------------------
# huggingface-hub is pinned to 0.36.2 and CAPPED below 1.0 because two packages
# in this stack both reject the 1.x major:
#   * transformers 4.56.0  requires  huggingface-hub>=0.34.0,<1.0
#   * tokenizers 0.22.0    requires  huggingface-hub>=0.16.4,<1.0
# The intersection of the whole stack's huggingface-hub ranges is therefore
#   >=0.34.0  AND  <1.0
# (datasets 5.0.1 allows <2.0 and accelerate 1.15.0 only needs >=0.21.0, so they
# are not the binding constraint). The 1.24.0 that was present in the broken
# test environment is a newer major that both transformers and tokenizers refuse,
# which is exactly why the calibration end-to-end test failed at import time.
#
# FUTURE UPGRADES
# ---------------
# To move past these pins, bump transformers + tokenizers + huggingface-hub
# together (they share the <1.0 / >=0.34.0 coupling), re-run
# `pip check`, and re-run the full suite. Do NOT raise huggingface-hub to 1.x
# until transformers and tokenizers both declare a 1.x-compatible bound.
#
# This set matches the versions the 8093 service runs in the ComfyUI env for the
# shared ML stack (torch 2.13.0 / transformers 4.56.0 / huggingface-hub 0.36.2 /
# tokenizers 0.22.0 / safetensors 0.8.0), so training and serving stay aligned.
